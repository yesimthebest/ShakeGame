# Shake Count

Webcam-based wrist crossing game built with Vite, React, TypeScript, and MediaPipe Pose Landmarker.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, then press `Start`.

## Build

```bash
npm run build
```

## Notes

- Webcam permission is required.
- MediaPipe model and wasm assets are loaded from public CDN URLs at runtime.
